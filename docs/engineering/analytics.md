# Analytics

Analytics are derived from persisted application facts, not model-generated estimates.

Current metrics:
- total meetings visible to the user
- completed meeting count
- average duration only where both start/end timestamps exist
- completed AI insight count
- action-item completion rate excluding dismissed actions
- meeting lifecycle breakdown
- 12-week meeting count/minutes series

The frontend intentionally avoids unverifiable metrics such as “AI hours saved” until the application has a defensible measurement methodology.
